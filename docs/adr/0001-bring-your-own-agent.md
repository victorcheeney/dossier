# The Candidate brings their own Agent; Dossier has no AI

Dossier contains no model, no API key and no chat. Everything that needs intelligence (finding a Posting and its Fields, drafting Answers, tailoring the Résumé, reading email to move an Application's Stage) is done by the AI chat the Candidate already uses, connected over MCP. The app only stores records, renders the page and exposes tools.

We chose this over a built-in chat because the Candidate already pays for and trusts an Agent that can read their files, their email and the web; a built-in chat would need its own API key and costs, and could do less. The cost is that Dossier is unusable without an MCP-capable Agent, and the quality of every draft depends on the Candidate's Agent, not on us.
