How it works

  1. Build your profile

    Talk it through with your AI. It also reads the sources you've connected to it, like your notes, your code or your LinkedIn profile in your browser, then writes your career history, accomplishments, base résumé, how you write and what you want next.

  2. Paste a posting you like

    Give your AI the link. It fetches the posting, reads the form's questions and adds the application to Dossier.

  3. Highlight what matters

    Mark the parts of the posting that speak to you and say why.

  4. Your AI drafts

    It combines your profile, the posting and your highlights to tailor your answers and résumé to the role.

  5. Review and send

    Edit anything on the page, then submit the application yourself.

Get started

  1. Install and start Dossier

    You need Node.js 24. Dossier opens at http://localhost:4747.

    git clone https://github.com/victorcheeney/dossier.git && cd dossier && npm install && npm start

  2. Connect your agent

    Run the one for the agent you use, once.

    Claude Code

    claude mcp add --transport http dossier http://localhost:4747/mcp

    Codex

    codex mcp add dossier --url http://localhost:4747/mcp

  3. Paste a job posting in your agent's chat

    Your agent adds the application, reads the form's questions and asks what each answer should say. Open Dossier to highlight, review and edit. Want to look around first? Click "Try the Example" on Dossier's first page.
